# Changelog

All notable project changes are documented here.

## 0.2.0
- Added Device Intelligence fields for Android low-memory state, device low-RAM class, power-save mode, battery percentage, display modes and OS-reported SoC data.
- Added on-demand diagnostic sampling without background polling.
- Added a dedicated Game Session Lab for Free Fire and Free Fire MAX.
- Added app-private session persistence capped at 20 records.
- Added pure session comparison logic and unit tests.
- Expanded preflight diagnostics and the device dashboard.

## 0.1.0
- Established modular Android/Kotlin foundation.
- Added read-only device diagnostics dashboard.
- Added separate Free Fire and Free Fire MAX package profiles.
- Added recommendation engine and unit tests.
- Added GitHub Actions build/test workflow and engineering documentation.
